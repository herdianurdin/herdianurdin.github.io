Bertahan sebagai _solo developer_ di ekosistem Google Play bukanlah tentang siapa yang bisa membuat aplikasi paling canggih dalam semalam. Ini adalah permainan daya tahan, konsistensi pemeliharaan kode, dan kemampuan menelan ego saat berhadapan dengan penolakan algoritma.

Jauh sebelum saya memahami arsitektur aplikasi berbasis Kotlin atau optimasi _App Store Optimization_ (ASO), perjalanan ini dimulai dari ruang yang jauh lebih berantakan.

## Fase Kebingungan dan Kematian Teknologi

Tahun 2015, saya memulai semuanya sebagai seorang _blogger_ SMP yang labil. Saya membangun blog, melihat grafiknya naik, merasa tidak percaya diri, lalu menghapusnya. Siklus destruktif ini terus berulang. Di era itu, saya belum menyentuh baris kode sama sekali. Pemahaman teknologi saya terbatas pada instalasi ulang sistem operasi, _cleaning_ PC teman, dan bereksperimen dengan Linux Ubuntu.

Memasuki masa SMA (2016-2019), eksplorasi teknologi saya nyaris mati. Tidak ada pelajaran relevan, perangkat yang terbatas, dan kondisi finansial keluarga yang sedang terpuruk menutup akses saya untuk "ngoprek". Fase ini dipenuhi rentetan kegagalan akademis—dari penolakan SNMPTN, kegagalan SBMPTN, hingga tes kedinasan yang nihil hasil. Saya akhirnya masuk ke jurusan Teknik Informatika di sebuah kampus swasta di Cianjur, lebih karena tuntutan keluarga agar anaknya menjadi sarjana daripada ambisi pribadi.

## Pelajaran Pahit dari Akun Konsol Pertama

Tahun 2020 adalah titik balik. Di tengah krisis keuangan dan pandemi COVID-19, saya mulai mengambil berbagai pelatihan gratis di Dicoding—meraba-raba mulai dari _Machine Learning_, _Web Development_, hingga _Android_.

Di tengah keputusasaan mencari arah, saya membuka akun Google Play Console pertama saya. Karena buta terhadap aturan hak cipta dan kebijakan Google, saya merilis kloningan _Flappy Bird_ menggunakan aset dan karakter asli. Hasilnya? Aplikasi penuh _bug_, rentetan peringatan pelanggaran hak cipta, dan berujung pada _banned_ permanen akun tersebut.

> **Pelajaran Teknis Pertama:** Google Play tidak memberikan ruang untuk kelalaian aset. Kegagalan ini memaksa saya memahami bahwa _development_ bukan hanya soal kode yang bisa di-_compile_, tapi soal orisinalitas, lisensi, dan kepatuhan absolut terhadap kebijakan ekosistem.

## Pivot ke Native Kotlin dan Kampus Merdeka

Menolak menyerah, saya mengikuti Jabar Coding Camp Batch 1 untuk kelas React Native dan keluar sebagai lulusan terbaik. Namun, tumpukan _framework_ _hybrid_ seperti Flutter dan React Native di otak saya justru membuat bingung. Akhirnya, saya mengambil keputusan arsitektural yang paling krusial: **kembali murni ke pengembangan Android Native menggunakan Kotlin.**

Keputusan ini diperkuat saat saya lolos program Kampus Merdeka bidang Android Developer dari Dicoding. Menjalani program ini bersamaan dengan beban kuliah normal, KKN, dan pengusulan UP—karena kampus tidak memberikan kompensasi jadwal—adalah masa yang paling menguras fisik dan mental. Namun, saya berhasil bertahan dan kembali menjadi lulusan terbaik.

Sebagai bentuk tanggung jawab atas ilmu yang didapat, saya membuat akun Play Console baru. Aplikasi pertama yang saya rilis adalah **[Buku Algoritma dan Pemrograman](https://play.google.com/store/apps/details?id=buku.belajar.algoritmapemrograman)**.

Kurangnya mentor membuat saya buta arah soal monetisasi dan promosi, sampai akhirnya saya mengikuti kelas bersama Pak Rysa Sahrial, _founder_ Aliendroid. Dari sana, pemahaman saya tentang _App Store Optimization_ (ASO), riset kata kunci, tahap produksi, hingga strategi penempatan iklan (AdMob) mulai terbentuk.

## Mengapa Aplikasi Saya Tetap Bertahan?

Banyak _developer_ pemula yang _hype_ di awal lalu menghilang karena aplikasi mereka ditangguhkan ( _suspended_ ) oleh Google. Mengapa aplikasi saya bertahan bertahun-tahun tanpa ada pengembangan fitur baru secara masif? Jawabannya ada pada **rutinitas pemeliharaan teknis**.

```kotlin
// Contoh rutinitas pembaruan dependensi di build.gradle.kts
dependencies {
    // Memastikan core KTX selalu mengikuti standar API level terbaru Google
    implementation("androidx.core:core-ktx:1.13.1")

    // Pembaruan krusial untuk mencegah pemblokiran iklan
    implementation("com.google.android.gms:play-services-ads:23.0.0")

    // Pemeliharaan Room Database untuk mencegah memory leak
    implementation("androidx.room:room-runtime:2.6.1")
    ksp("androidx.room:room-compiler:2.6.1")
}
```

Saya secara rutin melakukan:

1. Pembaruan versi SDK Target (API Level) setiap kali Google mengeluarkan mandat baru.
2. Memperbarui dependensi kunci seperti _AdMob SDK_ dan _User Messaging Platform (UMP)_ untuk kepatuhan privasi (GDPR).
3. Melakukan perbaikan kode minor (_refactoring_) untuk menyesuaikan dengan kebijakan Android terbaru.

## Resolusi Akhir 2026

Hari ini, banyak penawaran masuk ke kotak masuk email saya yang berani membeli akun Konsol Developer ini di angka $1.000 hingga $2.000. Tawaran itu selalu saya tolak.

Saat ini, keseharian saya dari Senin hingga Sabtu tersita oleh tanggung jawab sebagai guru dan operator sekolah. Perangkat lunak dan perangkat keras saya mulai tertinggal zaman, memori mulai penuh, dan harga komponen terus merangkak naik. Namun, pondasi teknis dan aset digital yang sudah berjalan ini adalah bukti nyata dari hasil jerih payah masa lalu.

Semoga, di akhir tahun 2026 ini, saya bisa kembali menyisihkan waktu dan _budget_ untuk memperbarui "senjata" (_device_), memperdalam ilmu kembali, dan terjun sepenuhnya sebagai _Software Developer_.
