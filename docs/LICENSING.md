## Status lisensi

Repository Jurnal IT menggunakan **Proprietary License — All Rights Reserved**, bukan MIT, Apache-2.0, GPL, Creative Commons, atau lisensi open source lainnya. File legal notice berada di root repository sebagai [`LICENSE.md`](../LICENSE.md).

Maksud pemilik adalah agar penggunaan ulang, penyalinan independen, modifikasi, penerjemahan, distribusi, publikasi, hosting, atau deployment materi milik proyek hanya dilakukan setelah memperoleh izin tertulis. Permintaan izin diarahkan ke [profil GitHub pemilik](https://github.com/herdianurdin).

## Batasan penting karena repository bersifat publik

Ada perbedaan antara **hak cipta pemilik** dan **hak yang diberikan GitHub melalui platform**:

1. Menurut dokumentasi GitHub, tanpa lisensi, default copyright berlaku; pemilik tetap memegang hak atas source code dan pihak lain tidak otomatis memperoleh lisensi umum untuk menggandakan, mendistribusikan, atau membuat karya turunan.
2. Akan tetapi, ketika repository dibuat publik, GitHub Terms of Service memberi pengguna GitHub hak untuk melihat dan melakukan fork repository di dalam layanan GitHub. Terms juga memberi GitHub hak tertentu untuk meng-host, menampilkan, mengindeks, dan membuat salinan yang diperlukan untuk menyediakan layanan.
3. Karena itu, `LICENSE.md` ini tidak mengklaim dapat menonaktifkan tombol Fork atau mencegah semua bentuk pengambilan salinan secara teknis. Notice ini menyatakan tidak adanya izin tambahan dari pemilik untuk penggunaan ulang di luar hak terbatas yang diberikan GitHub atau hukum yang berlaku.
4. Jika tujuan pemilik adalah **mencegah publik melihat dan melakukan fork repository**, ubah visibility repository menjadi private. GitHub menjelaskan bahwa mengubah repository publik menjadi private tidak menghapus fork atau salinan lokal yang sudah dibuat oleh pengguna lain.

Sumber resmi: [GitHub Docs — Licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) dan [GitHub Terms of Service, khususnya bagian D.4–D.9](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service).

## Materi pihak ketiga

Repository menggunakan dependency, framework, font, library, dan mungkin materi/aset pihak ketiga. `LICENSE.md` tidak mengubah lisensi atau hak pihak ketiga. Sebelum menggunakan ulang aset tertentu, periksa notice dan sumber aslinya. Jangan menganggap seluruh isi `public/images/` atau seluruh dependency sebagai hak eksklusif pemilik repository.

## Catatan legal

Dokumen ini adalah draf notice proprietary untuk menyatakan kehendak pemilik proyek, bukan pendapat hukum atau jaminan bahwa setiap klausul akan berlaku sama pada semua yurisdiksi dan keadaan. Karena repository bersifat publik dan tunduk pada GitHub Terms of Service, pemilik sebaiknya meminta review praktisi hukum Indonesia sebelum mengandalkan dokumen ini untuk sengketa atau aktivitas penegakan hak cipta.

Dasar hukum Indonesia yang relevan untuk dikonsultasikan adalah [UU Nomor 28 Tahun 2014 tentang Hak Cipta](https://peraturan.bpk.go.id/Download/28018/UU%20Nomor%2028%20Tahun%202014.pdf).
